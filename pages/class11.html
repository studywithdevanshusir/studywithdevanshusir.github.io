1. Computer System

A computer system is the combination of hardware and software that works together to perform tasks. Hardware includes the physical parts like CPU, memory and storage, while software gives instructions. Understanding basic parts helps you know how programs run and how data is stored. This chapter builds foundational vocabulary and simple diagrams.

2. Encoding Schemes & Number System

This chapter explains how computers represent numbers and text using binary, decimal and simple encoding like ASCII. You will learn why binary is used, how to convert small numbers between bases and how characters are stored. The focus is on intuition, simple worked examples and why these ideas matter for programming.

3. Emerging Trends

Emerging trends cover modern developments like cloud computing, basics of artificial intelligence and how technology is changing society. This chapter gives a gentle survey so students know what fields exist and how computer science connects to real-world problems. No deep math — just direction and examples.

4. Introduction to Python

An easy introduction to Python programming: how to write a simple program, run it and understand inputs and outputs. We cover basic statements, variables and how Python thinks about numbers and text. The goal is to make students comfortable writing their first programs without jargon.

5. Flow of Control

Flow of control explains how programs make decisions and repeat tasks using conditionals and loops. Students will learn if‑else statements, for and while loops with simple examples that show when to use each. This chapter builds problem‑solving skills step by step.

6. Functions

Functions are named blocks of code that do one job. This chapter introduces how to write simple functions, pass inputs (parameters) and return outputs. We emphasise clear examples and why functions help keep programs short, readable and reusable.

7. Lists

Lists store a sequence of items, like a number list or names. We cover creating lists, accessing elements, simple looping, and common uses like storing scores. The explanations focus on everyday examples so students see why lists are useful in programs.

8. Tuples & Dictionaries

Tuples are fixed collections and dictionaries map keys to values. This chapter explains the difference between them and lists, with simple examples like storing a student's details or a phonebook. We focus on when each type is best to use.

9. Strings

Strings are sequences of characters used for text. Learn the basics: creating strings, combining them, simple slicing and common tasks like formatting output. The focus is on practical examples such as names, messages and simple parsing tasks.

10. Computer Networks

An introduction to how computers communicate: local networks, the internet and simple ideas like servers and clients. Students learn why networks are important, how data moves and basic safety tips to keep online activities secure.

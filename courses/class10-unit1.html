Chapter 1: Styles in Document

Concept: Styles ka matlab hai document ko professional look dena bina bar-bar font change kiye. Imagine karo aapko 50 pages ki heading red karni hai. Ek-ek karoge toh ghanto lagenge. Styles se ye 1 second mein ho jata hai.

Definition: A style is a set of formats that you can apply to selected pages, text, frames, and other elements in your document to quickly change their appearance.

To use styles, we use the Styles and Formatting window. Check steps below:

  • Open your document in Writer.
  • Press F11 key (Shortcut).
  • OR go to Format > Styles and Formatting.

Types of Styles (Important for Exam)

  • Paragraph Styles: Control paragraph appearance (indents, alignment).
  • Character Styles: Affect selected text inside a paragraph (font, size, bold).
  • Page Styles: Page layout (margins, header, footer).
  • Frame Styles: Formatting graphics and text frames.
  • List Styles: Numbering and bullets.

Chapter 2: Images in Document

Text ke beech mein photo lagana document ko attractive banata hai. But photo sahi jagah adjust kaise karein? Iske liye hum Text Wrapping aur Anchoring use karte hain.

[Diagram: Anchoring & Text Wrapping Options Screenshot]

Text Wrapping Options:

  • Wrap Off: Text upar aur neeche, image beech mein.
  • Page Wrap: Text image ke charo taraf (Square).
  • Optimal Page Wrap: Text adjusts automatically.
  • Wrap Through: Image text ke upar (Transparent).

Quiz Time! (Board Exam Special)

Q1. Which key is used to open Styles window?

(a) F5 (b) F11 (c) Ctrl+S (d) Shift+F11
Answer: (b) F11

Q2. Which style affects the page layout including margins?

(a) Frame Style (b) Page Style (c) Paragraph Style (d) Character Style
Answer: (b) Page Style

Q3. To put text BEHIND an image, which wrapping option is used?

(a) Wrap Off (b) Page Wrap (c) Wrap Through (d) Optimal
Answer: (c) Wrap Through
